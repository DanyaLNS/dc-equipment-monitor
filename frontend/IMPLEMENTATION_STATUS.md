# Статус реализации Frontend

| Требование | Реализация | Проверка | Статус |
| --- | --- | --- | --- |
| Вход, восстановление, выход и роли | `/auth/login`, `/auth/me`, `/auth/logout`, cookie и CSRF в памяти, ожидание по Retry-After, операции ADMIN | API-тесты и браузерный сценарий обеих ролей на тестовых ответах | Реализовано |
| Сводка и стойки | Серверные показатели, поиск, страницы, CRUD, сообщение при удалении непустой стойки | Сводка и список в Chromium, компонентные тесты формы | Реализовано |
| Оборудование | Реестр, поиск, фильтры, страницы, CRUD, переключатель мониторинга, все страницы справочника стоек | Chromium, в форме доступна стойка со второй страницы справочника | Реализовано |
| Порты и история | Один GET `/view`, состояния и диагностика по портам, CRUD и переключатель, история со снимками адреса и порта, фильтры периода и результата | Chromium, два независимых состояния, история со старым адресом, без запросов на каждый порт | Реализовано |
| Настройки и ETag | GET конфигурации перед правкой и удалением, If-Match, проверка сочетания параметров, перечитывание и сравнение после 412 с сохранением черновика | Компонентные тесты конфликта, черновика, диапазонов и 422 | Реализовано |
| Поллинг, отказ API, устаревание | 5 секунд, отмена на скрытии и смене параметров, тайм-аут, сохранение последнего ответа, монотонный отсчёт до `stale_at`, безопасные события | Vitest для отмены, отсутствия наложения, тайм-аута и событий. Chromium для 503 и STALE | Реализовано |
| Адаптивность и доступность | Русские строки, подписи, текстовые статусы, видимый фокус, прокрутка таблиц внутри контейнера, локальное время с часовым поясом | Chromium 159.0.8154.6 на macOS, все шесть размеров ТЗ и 640×360, без горизонтальной прокрутки страницы | Проверено в Chromium |
| Локальный запуск и сборка | Same-origin маршруты, dev/preview proxy, инструкции для общего прокси | `typecheck`, `lint`, 10 тестов и production-сборка. Прокси возвращает 503 при недоступности upstream | Проверено локально |
| Реальный Backend, общий запуск и матрица браузеров | Клиент обращается к API v1 в рабочем режиме | Исполняемый Backend и конфигурация общего запуска отсутствуют. Ветка `origin/feature/backend` содержит SQL-миграции | Сквозной запуск с сервером, общий прокси и матрица версий браузеров не проверены |

Фактические несовпадения Backend с контрактом определить без работающего HTTP API невозможно. Остаются проверки реальных серверных сессий и прав обеих ролей, CRUD и мониторинга двух портов, серверных 409/412/422/429, нагрузки и полной браузерной матрицы. Браузерная проверка интерфейса использовала ответы по контракту, отделённые от рабочего режима.
